# AT PROTOCOL LEARN 

This repository was created as a place to learn and explore AT Protocol. The learning process progresses through Go code and Markdown notes. It is aims to understand how AT Protocol is implemented is the real world by studying Bluesky's open-source Go code. The main goal is not only to study the existing code, but also to gain a deeper understanding of the protocol by reimplementing what we learn in our own code.
